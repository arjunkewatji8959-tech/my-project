# Reliever Request Update

Guard and Supervisor can request Holiday, Medical / Illness or Emergency leave. The request stores Name, Staff ID, Location Code, From Date, To Date and Reason. Admin/Master Admin get a Reliever Requests page, select an active Reliever at the same location, then Approve or Reject. Approved requests store and display the replacement Reliever ID, Name and Location. In-app notifications are created for both staff members; WhatsApp uses the existing Cloud API configuration when available.

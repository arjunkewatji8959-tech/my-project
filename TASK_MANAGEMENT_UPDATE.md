# SNDF Task Management Update

- Task Management is available in Master Admin, Admin, Field Officer, Officer, Supervisor and Guard dashboards.
- Only Master Admin and Admin can create/assign tasks.
- Master Admin can assign to Admin, Field Officer, Officer, Supervisor and Guard.
- Admin can assign to Field Officer, Officer, Supervisor and Guard.
- Tasks can be assigned by staff ID (including comma-separated multiple IDs) or by selecting multiple members.
- A multi-assignment creates an independent task record for each assignee, so each person has separate progress/status/report.
- Officer dashboard: Supervisor Management and Point Transfer have been removed.

# Reliever Request + Reliever Duty Update

- Field Officer can now view Reliever Requests for assigned locations.
- Admin and Master Admin can review and approve/reject requests and assign a same-location active Reliever.
- Request list clearly shows From Date -> To Date, request type, reason, requester, location, status and assigned Reliever.
- Guard/Supervisor Reliever attendance follows the Reliever Management assigned duty hours and assigned shift.
- Reliever can have one open Check-In at a time and one attendance record per shift/date; Check-Out closes that shift.
- Assigned shift schedules: 12H Day 08:00-20:00, 12H Night 20:00-08:00; 8H Morning 06:00-14:00, Evening 14:00-22:00, Night 22:00-06:00.
- Reliever check-in uses the same 30-minute shift-start window and location geofence as normal attendance.
- The Reliever Duty card is shown on Guard/Supervisor attendance pages when the logged-in staff member is marked as a Reliever.
